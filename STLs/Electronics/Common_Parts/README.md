# Common Electronics Parts

This directory contains STL files that are shared across multiple electronics box configurations.

## Files

### Mount Hinges

- **Mount_hinge_90_v03.stl** - Standard 90-degree mount hinge
- **Mount_hinge_long_90_v01.stl** - Extended 90-degree mount hinge

These mount hinge files are used by all electronics box variants:
- EASY_BRD_Box
- ERB_Box
- MMBv1_Box
- MMBv2_Box

## Usage

When building any of the electronics boxes, print the required mount hinges from this directory instead of from individual box directories.
