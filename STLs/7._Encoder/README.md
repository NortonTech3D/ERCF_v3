# Encoder Bearing Options

This directory contains variations of the ERCFv2 encoder for different bearing types.

## Common Parts

**[o]_Encoder_Slotted_Wheel_8_tooth.stl** - This encoder slotted wheel is shared by all encoder bearing variants (623, v623zz, and 625 bearings).

## Bearing Variants

### mm623zz bearing option (623_Bearing directory)
This variation uses the plain M623zz bearing that was part of the v1.1 kits. It is not as precise as the recommended v623zz bearing option but does work. If you opt for this version it is important that you carefully align your selector positions with your gates otherwise you might experience slightly different measurement in the forward vs. reverse direction.
